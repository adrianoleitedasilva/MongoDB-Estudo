# Mongo DB ![MongoDB](https://img.shields.io/badge/MongoDB-%234ea94b.svg?style=for-the-badge&logo=mongodb&logoColor=white) 

Este repositório foi criado com o objetivo de centralizar minhas anotações, exemplos práticos, consultas e aprendizados adquiridos durante meus estudos sobre MongoDB.

O MongoDB é um banco de dados NoSQL orientado a documentos, projetado para armazenar grandes volumes de dados de forma flexível, escalável e com alto desempenho. Diferente dos bancos de dados relacionais tradicionais, que organizam informações em tabelas, linhas e colunas, o MongoDB trabalha com documentos no formato BSON (Binary JSON), permitindo estruturas de dados mais dinâmicas e próximas da forma como aplicações modernas manipulam informações.

Sua adoção é bastante comum em aplicações web, APIs, sistemas distribuídos, projetos que exigem escalabilidade horizontal e cenários onde a flexibilidade do modelo de dados é um diferencial importante.

Este repositório existe como uma base de conhecimento pessoal e prática, servindo tanto para documentar minha evolução no aprendizado quanto para funcionar como material de consulta rápida no futuro. Aqui estarão reunidos conceitos fundamentais, comandos, exemplos de queries, operações de CRUD, modelagem de documentos, agregações, índices e outros tópicos relevantes do ecossistema MongoDB.

O objetivo é transformar teoria em prática, construindo um material organizado, útil e reutilizável ao longo da jornada de aprendizado.
